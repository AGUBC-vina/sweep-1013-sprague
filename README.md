# River Road Efficiencies — SWEEP BCFB 1013

Field-verification dashboard for the River Road Efficiencies project (SWEEP block grant agreement BCFB 1013, Walter Sprague Orchards, Chico, CA), awarded by the Butte County Farm Bureau under its CDFA State Water Efficiency & Enhancement Program block grant.

One self-contained page — all photos embedded, no external requests. Served by GitHub Pages at <https://agubc-vina.github.io/sweep-1013-sprague/>.
